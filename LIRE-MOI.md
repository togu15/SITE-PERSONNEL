# Site personnel de Thibaut Souchon

Version indépendante : accueil personnel, parcours interactif et contact. Les pages, logos et réseaux Vie rurale sont retirés. La version originale est conservée séparément.

## Publication GitHub Pages
Déposez le contenu de ce dossier à la racine du dépôt personnel : index.html doit être directement visible. Activez Settings > Pages > Deploy from a branch > main > / (root).

## Parcours
Les données reprises sont celles disponibles dans la copie locale. Elle contient encore une formation d’exemple à remplacer. Pour récupérer vos étapes plus récentes créées dans votre ancien générateur, reprenez ensemble parcours-data.js, data/parcours.json et le dossier assets/parcours/ de votre dernière exportation. Le générateur privé ne doit pas être publié.

La carte aérienne nécessite Internet. Le générateur original reste séparé et inchangé.


## Mise à jour : vision et informations légales
La page Ma vision reprend les thèmes fournis : agriculture, pastoralisme, gestion de projet, accompagnement des éleveurs et communication. Les pages Mentions légales et Confidentialité sont préparées pour un site personnel sans vente hébergé sur GitHub Pages, confirmé par l’éditeur. Aucun numéro de téléphone de GitHub ni adresse personnelle de l’éditeur n’a été inventé. Les coordonnées complémentaires requises selon le statut exact de l’édition et la pratique de conservation des e-mails restent à vérifier avant publication. Il ne s’agit pas d’une certification de conformité juridique.
